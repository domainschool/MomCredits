### Updated AI Agent Prompts (MVP 1)

#### Step 1: Foundational UI & Global Styling

**Prompt 1:**

> "Create a single-page React web application called **'MomCredits'**. The UI must be stunning, vibrant, and optimized for mobile-first usage. Use Tailwind CSS. The color palette should feature soft gradients of rose, sunset orange, and royal purple with gold accents. Use a sophisticated Serif font for headings and a clean Sans-Serif for body text. Implement a 'Glassmorphism' style for containers (semi-transparent with blur)."

#### Step 2: Data Structure & Logic

**Prompt 2:**

> "Create a JavaScript array of 10 objects named `coupons`. Each object should have an `id`, a `title`, a `description`, and a `style` object containing a specific gradient and an emoji icon.
> **Use these 10 ideas:** > 1. Master Chef Special (Dinner), 2. Zen Zone Pass (Quiet time), 3. Digital Detox (Tech help), 4. The 'Yes' Day (3 hours of yes), 5. Laundry Legend (Full service), 6. Car Spa (Clean & Gas), 7. Ultimate Bed-In (Breakfast), 8. Memory Lane (Photo organizing), 9. Grocery Hero (Shopping), 10. Garden Guardian (Plant care).
> Set up React state to track the `selectedCoupon` and the `mothersName` input."

#### Step 3: The "Fabulous" Card Grid

**Prompt 3:**

> "Build a responsive grid for the 10 coupons. Each card should feel 'fabulous'—use the specific gradients from the data, add a subtle hover-lift effect, and ensure the emoji icon is large and playful. On mobile, this should be a single or double-column scrollable list. When a card is tapped, add a glowing gold border to show it is selected."

#### Step 4: Personalization & Image Generation

**Prompt 4:**

> "Below the grid, add a stylized text input for 'Enter Mom's Name'. Below that, add a large, vibrant button labeled 'Generate Magic Coupon'.
> When clicked, show a full-screen Modal. This Modal should display a **Final Coupon Card** that combines the selected coupon's title/icon with the text: 'This Digital Coupon is officially granted to [Mom's Name]'.
> Use the `html2canvas` library to allow the user to click a 'Download & Share' button. This button should capture the Final Card as a PNG and trigger a download so they can easily send it via WhatsApp or iMessage."

#### Step 5: Mobile Polish

**Prompt 5:**

> "Ensure the final UI has zero horizontal scroll on iPhone and Android screens. Add a confetti explosion effect (using `canvas-confetti`) when the 'Generate Magic Coupon' button is clicked. Make sure the download button is large and easy to tap with a thumb."
