## 📖 The Vision: Because 'Nothing' is Everything

When you ask a Mom what she wants, the answer is often **"nothing."** But "nothing" actually translates to a moment of peace, a helping hand, or a simple "I’ve got this." 

**MomCredits** was engineered on the belief that love isn't measured by a price tag, but by the time we give back. This application offers a frictionless, beautiful UI for users to generate digital promises—commitments to show up in the small ways that matter most. No stores, no shipping, just pure intention wrapped in a premium digital experience.

## ✨ Core Features & Functionality

- **The "Fabulous" Card Grid:** A meticulously crafted, responsive grid featuring a library of predefined, emotionally resonant favors (e.g., *The Zen Zone Pass*, *Laundry Legend*, *Master Chef Special*).
- **Dynamic Personalization Engine:** Intelligent text-input handling that automatically context-maps the user's name to generate personalized placeholders (e.g., `Prateek's Mother`).
- **"Create Your Own" Customizer:** An integrated, inline-editable card component allowing users to define custom favors and descriptions on the fly.
- **High-Fidelity Image Generation:** Seamless integration with `html2canvas` to render the DOM elements into a crisp, downloadable PNG artifact optimized for iMessage and WhatsApp sharing.
- **Premium Glassmorphism Aesthetic:** A modern UI utilizing Tailwind CSS to achieve frosted glass effects (`backdrop-blur`), soft glowing gradients, and smooth micro-interactions (hover-lifts, floating action bars).
- **Interactive Roadmap Engine:** A dedicated "Evolution & Community" UI featuring a vertical stepper that tracks product maturity (from MVP to Global Scale) to drive open-source contributions.

## 🏗 Technical Architecture

This application follows modern frontend best practices, optimizing for immediate interactivity, zero-layout-shift mobile rendering, and high-quality visual outputs.

| Technology | Purpose |
| :--- | :--- |
| **React 18** | Core UI component architecture and state management. |
| **TypeScript** | Strict type-safety across coupon data models and component props. |
| **Vite** | Blazing-fast HMR and optimized production build bundling. |
| **Tailwind CSS (v3)** | Utility-first styling engine powering the glassmorphism and gradient system. |
| **Lucide React** | Scalable, clean SVG iconography. |
| **HTML2Canvas** | Headless DOM-to-Image rendering for the "Download & Share" capability. |
| **Canvas Confetti** | High-performance particle physics engine for user-reward micro-animations. |

## 🚀 Getting Started

To run the application locally and contribute to the "Language of Love":

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/mom-credits.git
   cd mom-credits
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Navigate to `http://localhost:5173` to view the application.
